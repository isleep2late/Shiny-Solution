Gen 2 shiny DV checker (also: will my Gen 1 mon be shiny in Gen 2?)

The rule (from the Crystal decompilation): Defense, Speed and Special DVs must all be exactly 10, and the Attack DV must be one of 2, 3, 6, 7, 10, 11, 14, 15. That is 1/8192. Gen 1 has no shininess of its own — but the Time Capsule copies DVs unchanged, so a Gen 1 mon with these DVs IS shiny once traded to Gen 2.

Automated shiny hunting for Gen 1/2 needs an emulator: it is part of the Windows desktop app driving mGBA, not this web version.

Emerald / FireRed / LeafGreen: the Secret ID from a typed Trainer ID

      
These games cannot have their Trainer ID chosen: it is the raw Timer1 count at the instant the player
      naming screen finishes fading out. That count seeds the RNG, which then advances once per VBlank until the
      Secret ID is rolled, so SID = high 16 bits of LCRNG^(k+1)(TID) with k the VBlank count from the seed to the
      roll. [TARGET] The Trainer ID is human input: read it off the Trainer Card and type it; nothing reads the game.
      The press cue pins k to a window of 27 instead of 1201; a pin (a PID you can see is shiny or not) narrows the list to one.

About

      
Shiny-Solution manipulates the actual RNG of the classic Pokémon games: every mechanic
      here was verified against the pret decompilations. This web version covers everything that
      needs no emulator: searchers, calculators, checkers and calibrated timers for real-hardware
      manipulation.

      
Modes: RUN is the default and is human input only (an anchor press, a typed outcome; run-legal).
      PRACTICE / HUNT is turned on with the switch above the tabs and shows a banner on every tab while it is
      on; it keeps its own calibration stores, and every record and cue log says which mode it was made in.
      This page has no tool that reads a capture: those live only in webapp/hunt/ (never bundled
      into the site, the phone bundle or the desktop builds without an explicit --with-hunt) and
      in RNG Solution's watch --practice.

      
The full desktop version additionally drives the mGBA emulator for frame-perfect
      automatic manipulation (Gen 3) and automated savestate hunting (Gen 1/2):
